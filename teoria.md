## 📚 Теория

### 1. Что такое Python?
Интерпретируемый язык программирования. Код читается сверху вниз, строки выполняются по порядку. Не нужно компилировать — просто пишешь и запускаешь.

### 2. Переменные
Переменная — это "коробка" с именем, куда кладётся значение.

```python
name = "Аня"      # строка (str)
age = 25          # целое число (int)
height = 1.68     # дробное число (float)
is_student = True # логическое значение (bool)


Правила именования:

латиница, цифры, _ (без пробелов и дефисов)

не начинается с цифры

регистр важен: age и Age — разные переменные

стиль: snake_case (например, user_name)

3. Типы данных (основные)
Тип	Пример	Что это
int	42	целое число
float	3.14	дробное
str	"привет"	строка
bool	True / False	логика
None	None	"ничего"/пустота
Проверить тип: type(age) → <class 'int'>


print("Привет, мир!")          # вывод
print("Возраст:", age)          # несколько значений

name = input("Как тебя зовут? ") # ввод (всегда строка!)


⚠️ input() всегда возвращает строку. Чтобы получить число — int(input()) или float(input()).
