# 🐍 Python для начинающих: урок 1

## 📚 Теория

### 1. Что такое Python?

Интерпретируемый язык программирования. Код читается сверху вниз, строки выполняются по порядку. Не нужно компилировать — просто пишешь и запускаешь.

### 2. Переменные

Переменная — это «коробка» с именем, куда кладётся значение.

```python
name = "Аня"       # строка (str)
age = 25           # целое число (int)
height = 1.68      # дробное число (float)
is_student = True  # логическое значение (bool)
```

**Правила именования:**

- латиница, цифры, `_` (без пробелов и дефисов);
- не начинается с цифры;
- регистр важен: `age` и `Age` — разные переменные;
- стиль: `snake_case` (например, `user_name`).

### 3. Типы данных (основные)

| Тип     | Пример          | Что это          |
|---------|-----------------|------------------|
| `int`   | `42`            | целое число      |
| `float` | `3.14`          | дробное          |
| `str`   | `"привет"`      | строка           |
| `bool`  | `True` / `False`| логика           |
| `None`  | `None`          | «ничего»/пустота |

Проверить тип: `type(age)` → `<class 'int'>`

### 4. Вывод и ввод

```python
print("Привет, мир!")             # вывод
print("Возраст:", age)            # несколько значений

name = input("Как тебя зовут? ")  # ввод (всегда строка!)
```

> ⚠️ `input()` всегда возвращает **строку**. Чтобы получить число — `int(input())` или `float(input())`.

### 5. Арифметика

```python
10 + 3   # 13
10 - 3   # 7
10 * 3   # 30
10 / 3   # 3.333... (всегда float)
10 // 3  # 3 (целочисленное деление)
10 % 3   # 1 (остаток)
10 ** 3  # 1000 (степень)
```

### 6. Строки — базовое

```python
s = "Python"
len(s)      # 6 — длина
s[0]        # 'P' — первый символ
s[-1]       # 'n' — последний
s[0:3]      # 'Pyt' — срез
s.upper()   # 'PYTHON'
s.lower()   # 'python'
"a" + "b"   # 'ab' — склейка
"ha" * 3    # 'hahaha'
```

### 7. Комментарии

```python
# однострочный
"""многострочный
(на самом деле это строка, но используют как комментарий)"""
```

## 💪 Практика

### Задание 1. Разминка

Создай переменные: своё имя, возраст, рост, любишь ли ты Python (bool). Выведи их через `print` в одной строке.

### Задание 2. Калькулятор

Запроси у пользователя два числа и выведи:

- сумму;
- разность;
- произведение;
- частное;
- остаток от деления.

### Задание 3. Анкета

Запроси имя и возраст. Выведи:

> Тебя зовут `<имя>`, тебе `<возраст>` лет. Через 5 лет тебе будет `<возраст + 5>`.

### Задание 4. Строки

Дана строка `s = "Программирование"`. Выведи:

1. её длину;
2. первый и последний символ;
3. первые 5 символов;
4. строку в верхнем регистре;
5. строку задом наперёд (подсказка: срез `[::-1]`).

### Задание 5. Со звёздочкой 🌟

Запроси у пользователя сумму в рублях и курс доллара. Выведи, сколько это в долларах, округлив до 2 знаков после запятой (подсказка: `round(x, 2)`).
